    WAŻNE O AI

    Jak podłączyć prawdziwą sztuczną inteligencję?

    GitHub Pages hostuje statyczne pliki i samo nie uruchomi prywatnego klucza API. Aby model AI tworzył nowe przepisy na żądanie, potrzebny jest endpoint serwerowy (np. funkcja Cloudflare Workers lub Netlify Functions), który przechowuje klucz poza przeglądarką.

    Po skonfigurowaniu endpointu ustaw w script.js adres w zmiennej AI_ENDPOINT. Oczekiwany endpoint przyjmuje JSON {"ingredients":[],"time":30,"budget":12,"style":"any"} i zwraca JSON z polami: name, description, time, cost, ingredients (tablica tekstów) oraz steps (tablica instrukcji).

    Nie wklejaj klucza API do pliku JavaScript ani publicznego repozytorium. Obecny generator korzysta z przygotowanej bazy i działa bez połączenia z AI.
