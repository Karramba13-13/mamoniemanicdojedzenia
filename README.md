# Co dziś na obiad? — starter

Prosta, statyczna strona po polsku z planerem posiłków.

## Co działa
- filtrowanie przepisów po budżecie, czasie i rodzaju dania,
- losowanie pomysłu na obiad,
- dodawanie i usuwanie dań z planu,
- automatyczna lista składników,
- kopiowanie listy zakupów,
- układ dostosowany do telefonów i komputerów.

Dane są przykładowe. Plan nie jest zapisywany po odświeżeniu strony; to wersja startowa bez bazy danych i kont użytkowników. Koszty porcji są orientacyjne.

## Uruchomienie lokalne
Otwórz plik `index.html` w przeglądarce. Nie trzeba instalować programów.

## Publikacja za darmo przez GitHub Pages
1. Zaloguj się lub załóż konto na https://github.com/
2. Kliknij **+** w prawym górnym rogu, a potem **New repository**.
3. Nazwij repozytorium `co-dzis-na-obiad`. Ustaw **Public** i kliknij **Create repository**.
4. W repozytorium kliknij **Add file → Upload files**.
5. Wgraj pliki `index.html`, `style.css`, `script.js` i `README.md` z tego folderu. Ważne: `index.html` ma być w głównym katalogu repozytorium, a nie w dodatkowym podfolderze.
6. Kliknij **Commit changes**.
7. Otwórz **Settings → Pages**.
8. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
9. Wybierz branch `main` i folder `/(root)`, a następnie kliknij **Save**.
10. Po chwili GitHub pokaże adres strony w sekcji Pages. Zwykle będzie miał postać `https://TWOJ_LOGIN.github.io/co-dzis-na-obiad/`. Zastąp `TWOJ_LOGIN` swoją nazwą użytkownika GitHub.
11. Jeśli strona się nie pojawia, odczekaj kilka minut i odśwież widok Pages. Sprawdź też zakładkę **Actions**, czy wdrożenie zakończyło się powodzeniem.

## Aktualizacje
Gdy chcesz zmienić stronę, otwórz plik w repozytorium na GitHubie, kliknij ikonę ołówka, wprowadź zmiany i kliknij **Commit changes**. GitHub Pages opublikuje nową wersję automatycznie.
